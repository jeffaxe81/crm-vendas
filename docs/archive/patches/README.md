# Patches históricos (FASE 1–3)

Arquivos `git format-patch` que estavam soltos na raiz do repositório.
Foram movidos para cá apenas para organização — **não são aplicados
automaticamente** por nenhuma ferramenta.

A pasta `patches/` na raiz é reservada para o `pnpm patch`
(ex.: `wouter@3.7.1.patch`) e não deve receber outros arquivos.
