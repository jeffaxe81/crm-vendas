# Manuais por perfil — Release 1.2

Este conjunto de manuais acompanha a Release 1.2 — Configuração Rápida.

## Como usar

O CRM deve apresentar prioritariamente o manual correspondente ao perfil da associação ativa do usuário.

| Perfil | Manual | Finalidade |
| --- | --- | --- |
| ADMIN | [Administrador](./admin.md) | Configurar organização, usuários, segurança e estrutura inicial |
| MANAGER | [Gestor](./manager.md) | Organizar a operação comercial e manter dados do CRM |
| SELLER | [Vendedor](./seller.md) | Executar a rotina comercial e manter relacionamento atualizado |
| VIEWER | [Consulta](./viewer.md) | Consultar informações sem alterá-las |

Consulte também a [Matriz de Permissões](./matriz-de-permissoes.md).

## Regra importante

Os manuais descrevem o que o perfil está autorizado a fazer e distinguem:

- **Disponível agora:** recurso existente na versão instalada;
- **Previsto:** permissão ou módulo reservado no RBAC/roadmap, mas que pode ainda não possuir tela funcional.

A interface nunca deve prometer acesso a um módulo indisponível apenas porque a permissão já existe no modelo de segurança.
