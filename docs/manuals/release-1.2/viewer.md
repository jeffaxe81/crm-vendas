# Manual do VIEWER — Release 1.2

## Para quem é

O VIEWER é destinado a usuários que precisam consultar informações comerciais sem alterá-las.

## O que pode fazer

O perfil possui permissões de leitura para:

- empresas;
- contatos;
- oportunidades;
- atividades;
- conhecimento.

A disponibilidade visual de cada módulo depende da versão instalada.

## O que não pode fazer

O VIEWER não deve:

- criar, editar ou excluir empresas;
- criar ou editar contatos;
- alterar oportunidades;
- movimentar etapas comerciais;
- criar ou editar atividades;
- alterar conteúdo de conhecimento;
- administrar organização;
- administrar usuários;
- consultar auditoria administrativa.

## Configuração rápida

Para VIEWER, a configuração rápida deve ser curta:

1. confirmar organização ativa;
2. apresentar as áreas disponíveis;
3. explicar como pesquisar e consultar dados;
4. apresentar este manual;
5. concluir sem exibir etapas administrativas.

## Boas práticas

- confirme sempre a organização ativa;
- utilize pesquisa e filtros disponíveis antes de solicitar novos cadastros;
- encaminhe correções ao responsável com permissão de escrita;
- não compartilhe credenciais;
- respeite a finalidade das informações acessadas.

## Quando solicitar ajuda

Procure um MANAGER ou ADMIN quando:

- um cadastro estiver incorreto;
- um contato precisar ser criado ou editado;
- uma tag/campo precisar ser alterado;
- o seu perfil parecer inadequado para a sua função.
