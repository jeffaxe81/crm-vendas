# Manual de ADMIN — planejamento 1.2

O ADMIN pode administrar a organização e seus usuários, consultar auditoria, parametrizar integrações e operar o CRM conforme as permissões do backend.

## Roteiro recomendado

1. Confirme a organização da sessão, para não confundir dados entre empresas.
2. Revise nome e parâmetros organizacionais disponíveis.
3. Crie e revise membros; conceda ADMIN apenas quando necessário e preserve pelo menos um administrador válido.
4. Configure etapas do funil, produtos, campos personalizados e tags nas telas realmente disponíveis.
5. Revise permissões, auditoria e configurações de integrações. Não habilite envio externo de e-mails enquanto permanecer bloqueado pelo ambiente.
6. Teste o cadastro de uma empresa, contato, oportunidade e atividade, e a persistência após nova sessão.
7. Oriente cada integrante com seu manual e o tour da versão 1.1 quando já instalado e homologado.

## Permissões diferenciadas

ADMIN inclui `organization.manage`, `user.manage`, `audit.read`, `reports.read`, `pipeline.manage`, `support.manage`, `integration.manage` e `integration.read`, além das permissões comerciais. Consulte a matriz para o quadro completo.

## Conclusão

- [ ] organização confirmada;
- [ ] membros e administradores conferidos;
- [ ] funil, produtos e campos essenciais revisados;
- [ ] política de acesso e auditoria conferidas;
- [ ] operação de ponta a ponta verificada no ambiente instalado.

**Nota:** esta sequência não representa execução automática do futuro wizard 1.2.
